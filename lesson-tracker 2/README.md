# HELEN’S MATH SECRETS · 课时管理

使用机构原版 Logo 和深绿色品牌主题的中英文课时管理网站，可在手机、平板和电脑使用。当前交付是可运行的独立网站源码和本机演示，尚未部署为供家长访问的公网服务。

## 学生档案与多科目

- “学生与课时”按学生档案分组，老板和管理员可编辑姓名、生日、年级及内部备注。内部备注不向家长或任课老师返回。
- 点击“添加科目”给现有学生关联课程，新科目从 0 课时开始，各科独立充值、扣课、退款及撤销；家长端也按孩子和科目显示。
- 排课时选择学生及扣课科目；同一学生不同科目的时间冲突也会被拒绝。
- “家长账号”可编辑家长姓名、登录手机号和联系手机号，或重置密码。原密码不可读取；留空保留密码。修改登录手机号或密码会使家长的原会话失效。共用账号的所有孩子同步受影响。
- 升级自动为旧学生课程记录创建档案关联，保留原有余额、课时流水与课程关联。不根据姓名自动合并已有记录。

## 老师管理

- 可编辑老师姓名、登录手机号及教学科目，支持一位老师多个科目；密码可留空保留或重置。
- 离职停用会退出其登录状态并阻止登录、新排课；历史课程保留，未完成课程需管理员另行调整任课老师。可恢复在职。
- 老板或管理员兼任老师的账号仅由老板在老师页面编辑教学科目，账号权限仍通过原管理入口处理。

## 付费与赠送课时

- 每次充值分别填写付费课时和赠送课时，形成一个批次；同一科目先消耗所有付费／历史余额，再消耗赠课。同类余额按批次录入顺序扣除。
- 退款必须选择充值批次，仅能退该批次剩余付费课时；部分退款也会作废该批次全部剩余赠课，其他批次不变。
- 流水分别记录付费变动、赠课变动和赠课作废；作废课时单独进入对账汇总，不当作现金退款课时。
- 纠错保留原记录并反向恢复原批次分配。已使用的充值不能直接撤销；涉及已退费批次的赠课恢复，需先撤销相关退款，防止重新启用已作废赠课。
- 升级前的余额作为“历史余额（未拆分）”保留，不推断其中的赠课。退历史余额前请核对原始充值资料。

## 新增功能

- 新增排课支持不重复、每周或每两周重复，总课次数包含首次，最多 52 次。跨夏令时保持机构当地时间；任一次冲突时整批不保存。各次课程独立调整、取消和结课扣课。

- 中英文界面切换，记住当前设备的语言；不翻译姓名、学习内容、作业及反馈原文。
- 老板独立权限：创建和停用管理员，查看每日、每周、每月账目。
- 充值时记录实际澳元收款，退课退款支持部分或全部课时，填写实际澳元退款及原因。系统仅记账，不执行银行转账。
- 账目区分收款、退款、纠错；历史缺失金额单独提示并支持补录。
- 老师独立账号、排课日历、小班课、学习内容、今日作业和课后反馈。保存草稿不扣课，完成课程才扣课并发布给家长。

## 已实现

- 家长使用老师开通的手机号和密码登录，只能看到关联孩子的余额和明细。
- 老师添加学生；一个家长账号可关联多个孩子或课程。
- 充值课时、登记上课、扣除 0.5 / 1 / 任意两位小数课时。
- 余额不足时拒绝扣除；重复提交不会重复扣课时；并发扣除不会超扣。
- 撤销时保留原记录并追加反向记录；显示日期、备注、登记人。
- 修改密码后原会话全部失效。
- 数据存入 SQLite，不依赖浏览器缓存；密码加盐哈希存储。

## 本机体验

需要 Python 3.10 或更新版本，无需安装第三方依赖。

```sh
cd lesson-tracker
LESSON_DEMO=1 LESSON_DB=./data/demo.sqlite3 python3 server.py
```

访问 http://127.0.0.1:8765 ，点击老板、管理员、任课老师或家长演示入口。演示使用虚构数据。

演示老板：0400000000 / TeacherDemo2026!

演示家长：0400000001 / ParentDemo2026!

**演示数据库只能用于演示。关闭演示开关不会删除这些已存在的公开账号，正式使用必须新建一个独立数据库。**

## 机构名称

启动时设置 `LESSON_ORG_NAME`，登录页、管理页和浏览器标题会使用机构名称。例如：

```sh
LESSON_ORG_NAME="你的机构名称" LESSON_DB=./data/production.sqlite3 python3 server.py
```

## 初始化正式账号

```sh
LESSON_DB=./data/production.sqlite3 python3 server.py --create-owner
LESSON_DB=./data/production.sqlite3 python3 server.py
```

按提示设置老师手机号、姓名、密码。不要设置 `LESSON_DEMO=1`。老师登录后添加学生并设置家长初始密码，再充值课时。已有家长手机号可再次使用，原密码不会改变。

手机号按输入格式匹配：例如 `+61412345678` 和 `0412345678` 被视为不同账号，机构应统一采用带国家区号的手机号。手机号在这里是登录名，当前没有短信验证、短信找回、微信登录或在线支付。家长注册由老师办理，不开放自行注册。

忘记密码时，服务维护者可以使用以下命令重设密码，已有会话随即失效：

```sh
LESSON_DB=./data/production.sqlite3 python3 server.py --reset-password
```

## 正式上线尚需完成

当前内置 Python HTTP 服务用于本机运行和验证，不应直接裸露到互联网。已新增正式 Gunicorn/WSGI 入口和 Render 部署配置。具体开通流程、费用估算与尚未完成的工作见 [上线指南](上线指南.md)。正式上线前仍需开通托管账号、部署服务、初始化老师账号、设置独立备份，并在实际 HTTPS 网址验证访问与隔离。

- 数据库需要持久化磁盘；不能放在会随部署销毁的临时文件系统。
- HTTPS 环境启用 `LESSON_SECURE_COOKIE=1`；正确设置域名和代理转发的 Host。
- 服务日期使用主机时区；部署时应设为机构实际时区。
- 生产反向代理应按真实来源 IP 限流。当前本机服务还会按手机号及连接 IP 限制失败登录，代理后共享 IP 可能造成共同限流。
- 备份应采用 SQLite backup API 或停止服务后复制数据库，不能只复制写入中的主文件而忽略 WAL。
- 请勿将正式数据库、账号密码或备份放入公开源码仓库。

## 验证

```sh
python3 test_app.py
```

集成测试使用独立临时数据库和本机 8766 端口，覆盖家长隔离、写入权限、小数计算、重复提交、并发超扣、撤销、CSRF 和修改密码。

文件：`server.py` 为服务和数据库逻辑；`static/` 为页面；`test_app.py` 为集成测试。

`wsgi.py` 和 `gunicorn.conf.py` 为正式服务入口；`render.yaml` 为预备部署配置（应用它会开通付费资源）；`backup.py` 为一致性备份工具。
